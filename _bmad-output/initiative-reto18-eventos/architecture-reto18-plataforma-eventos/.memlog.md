- (direction) Fast path elegido por el usuario; stack propuesto por el equipo: React, Next.js, NestJS, Redis, Docker, Supabase, Railway o VPS
- (constraint) Spec: demo en vivo <10 min, coste cero, pagos en prueba, respaldo por dependencia externa, WhatsApp con número de prueba, datos exactos en piezas, butaca nunca vendida dos veces, IGV incluido
- (version) Next.js 16.3.3 (parche de seguridad 25/08/2026; usar >=16.3.3)
- (version) NestJS 12 (requiere Node 20.19+ o 22.12+); Node 22 LTS
- (version) Evolution API v2 (imagen Docker) con PostgreSQL y Redis propios
- (decision) Paradigma: monolito modular — NestJS con un módulo por contexto (identidad, eventos, ventas, acceso, marketing, negocio, notificaciones, ia) + Next.js como cliente; previene que dos epics escriban las mismas tablas
- (decision) Solo la API NestJS escribe en la base; la web usa Supabase solo para Auth y para Realtime de lectura de butacas; previene reglas de negocio duplicadas en el cliente
- (decision) Redis no se usa en la app: bloqueo de butacas y aforo con UPDATE condicional atómico en Postgres; Redis solo como dependencia interna de Evolution API
- (decision) Mapa: el mapa pertenece a la sede (sección, fila, bloque, asiento); cada evento crea su inventario de asientos (event_seat) con categoría y estado; las categorías de precio son del evento
- (decision) Ventas: estados de asiento available -> held (expira a los 10 min) -> sold; orden pending -> paid | expired; la entrada se emite solo al confirmar el pago
- (decision) QR: token firmado HMAC con ticket_id; validación en línea = UPDATE atómico unused->used; sin conexión = manifiesto del evento en IndexedDB y cola de sincronización, gana el primer uso sincronizado
- (decision) Enlace rastreable: /r/{code} (base62 de 8) en la web; la API registra el clic y la atribución es al último clic, guardada en la orden
- (decision) WhatsApp: solo el módulo notificaciones habla con Evolution API, mediante una tabla outbox; los demás módulos encolan; teléfono en E.164 +51
- (decision) Dinero en céntimos de PEN (enteros), precios con IGV incluido; la comisión se calcula y congela en la orden
- (decision) Piezas: plantillas JSX renderizadas a PNG con next/og (ImageResponse) en la web a partir de datos de la API; la IA solo produce textos, paleta y campaña
- (assumption) Pasarela: Culqi con llaves de prueba y checkout alojado (tarjeta y Yape); Plin simulado; verificar por P2
- (assumption) Proveedor IA según créditos; por defecto Claude Sonnet 5.5 (claude-sonnet-5-5), con visión para CAP-3 y CAP-16
- (assumption) Despliegue: web en Vercel Hobby; API + Evolution en Railway con el crédito de prueba de 5 USD; respaldo: docker compose en el portátil de la demo
